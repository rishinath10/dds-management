Notes

EPF/SOCSO/EIS are calculated by percentage (not the official rounding tables), so figures may differ by a ringgit or two near month-end. Cross-check against the official KWSP/PERKESO tables before remitting if exact figures matter.

  • EPF wages = Basic + Allowances + Commission (OT excluded)
  • SOCSO/EIS wages = Basic + Allowances + OT + Commission, capped at RM6,000
  • PCB / income tax is not included — add manually if required.
